# LoomHarness на русском

LoomHarness помогает ИИ-агенту находить причину сбоя, нужную строку или показатель, сохраняя полный журнал на диске. На пяти тестовых журналах из комплекта краткий ответ занял 316 токенов против 8 391 у исходного вывода. Скрипт проверяет, что сохранились название упавшего теста, пропуск и код ошибки. [Таблица с замерами](README.md#token-benchmarks) · [Как повторить](docs/benchmarks.md)

## Быстрый старт

Нужны Git и Python 3.11 или новее. На macOS и Linux выполните эти команды.

```sh
git clone https://github.com/rubcov666/loomharness.git
cd loomharness
python3 -X utf8 install.py --cli codex
```

В PowerShell используйте `python` вместо `python3`. В Codex откройте `/hooks`, подтвердите четыре обработчика и напишите в чате проекта `LoomHarness on`. Выбор сохраняется для этой папки. Для отключения введите `LoomHarness off`.

Попросите агента запустить проверку. «Запусти тесты, покажи упавшие и пропущенные, сохрани полный журнал». Получив сводку, можно запросить детали. «Покажи пять строк вокруг первой ошибки». Команды чтения, поиска и просмотра отчётов также работают из терминала до установки хуков. [Пример для терминала](README.md#try-it-in-a-minute)

## Короткие и долгие задачи

- Для одного вопроса хватает текущего чата. Если нужен ответ из одной короткой строки, её проще прочитать целиком.
- Длинные тестовые прогоны можно сворачивать, одинаковые строки — считать, а из JSON выбирать поля. При необходимости агент открывает исходный файл.
- При работе команды доска хранит назначения, результаты проверок и ревизии. Расход участников за выбранный интервал показывает `team.py usage --summary`. [Совместная работа](loomharness/references/team.md)
- Для Claude Code, Gemini CLI, OpenCode и клиентов MCP доступны отдельные варианты подключения. [Интеграции](integrations/README.md)
