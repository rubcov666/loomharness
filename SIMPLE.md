# LoomHarness

[English](README.md) · **Русский** · Версия **1.2.1**

LoomHarness помогает ИИ-агентам экономить токены в задачах любого типа, от разработки и исследований до работы с документами и данными. Он локально отбирает нужные фрагменты файлов, журналов и таблиц. Полный исходник остаётся доступным. LoomHarness также помогает повторно использовать результаты проверок и распределять работу между агентами.

На клиентах с именованными субагентами координатор использует одного агента на роль и может добавить дизайнера или другого специалиста. Связанные проверки получает один агент, а результат каждой проверки записывается отдельно. [Работа с именованными агентами](loomharness/references/team.md#named-native-agents)

## Экономия токенов и денег

На двух тестовых задачах в Codex сравнили чтение целых файлов с выборкой нужных данных. Все ответы прошли одинаковые проверки.

| Модель | Всего токенов, без → с LoomHarness | Оценка стоимости API, без → с LoomHarness |
|---|---:|---:|
| GPT-6.2 Sol | 75 214 → 35 300 (**−53%**) | $0,0974 → $0,0173 (**−82%**) |
| GPT-6.2 Astra | 75 091 → 35 176 (**−53%**) | $0,3896 → $0,0501 (**−87%**) |

Стоимость рассчитана по тарифу OpenAI API Standard с учётом кеша. Миллион некешированных входных и миллион выходных токенов стоят соответственно $2 и $10 на Sol, $8 и $40 на Astra. [Подробные замеры и тарифы](docs/benchmarks.md#whole-task-token-usage-in-codex)

## Место на диске

В замере на Windows с одним активным проектом LoomHarness занял **1,79 МиБ** на диске. Сам инструмент занял **800 КиБ**, данные проекта — **998 КиБ**, общие файлы профиля — **32 КиБ**. Сохранённые журналы и кеши могут увеличить объём. [Как измеряли](docs/benchmarks.md#disk-footprint)

## Установка через ИИ-агента

Скопируйте этот промпт в чат агента с доступом к терминалу.

```text
Установи и настрой LoomHarness для этого проекта. Определи мою ОС и CLI, которым я пользуюсь.
Скачай ветку main из https://github.com/rubcov666/loomharness. Если репозиторий недоступен, попроси у меня ZIP.
Следуй integrations/README.md и используй Python 3.11 или новее. Выбери способ подключения для этого клиента.
Если для CLI нет отдельной интеграции, подключи loomharness/scripts/mcp_server.py через stdio MCP при поддержке клиента. Иначе используй инструменты Python через терминал.
Проверь подключение в этом проекте и сообщи, что работает. Если я должен подтвердить доверие или сам включить режим, покажи точный шаг.
```

## Инструменты

| Инструмент | Для чего нужен |
|---|---|
| `view.py` | Находит нужные строки и читает выбранные поля. |
| `context.py run` | Сохраняет полный вывод команды и показывает основные ошибки. |
| `context.py map` | Находит подходящие файлы и строки исходников. |
| `records.py` · `metrics.py` | Фильтрует записи, считает итоги и срабатывания. |
| `context.py reuse` · `context.py build-check` | Проверяет, подходят ли результаты предыдущих проверок. |
| `history.py budget` | Подсказывает, когда стоит сжать историю длинного чата. |
| `team.py` · `team.py usage` | Ведёт задачи, ответственных, ревью и расход токенов. |
| `harness.py doctor` · `context.py audit` | Проверяет подключение хуков и находит повторы в инструкциях. |
