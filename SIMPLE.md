# LoomHarness

[English](README.md) · **Русский**

LoomHarness помогает ИИ-агенту найти упавший тест, нужную строку исходного кода или число срабатываний. Полный вывод остаётся на диске. Если сводки мало, агент может открыть исходный журнал.

**3 704 577 → 11 514 токенов (−99,69%)** при разборе синтетических журналов сборки за восемь смоделированных запросов. В одном варианте каждый запрос включал полные журналы. В другом агент искал нужные записи и отдельно запросил пропущенное правило повторной проверки. Итоговые отчёты совпали, включая все ограничения, исключения и ссылки на источники. [Как считали токены](docs/benchmarks.md#eight-request-build-investigation)

**Версия 1.0.0** · Python 3.11+ · Windows, macOS и Linux

## Попробуйте за минуту

Понадобятся Python 3.11 или новее и Git. Запустите команду, которая 100 раз выводит одно и то же сообщение.

```sh
git clone https://github.com/rubcov666/loomharness.git
cd loomharness
python3 loomharness/scripts/context.py run --log demo.log -- python3 -c "for i in range(100): print('waiting for worker')"
```

В сводке появится `1-100: waiting for worker`. Откройте `demo.log`, чтобы увидеть все 100 исходных строк. При каждом запуске указывайте новое имя файла журнала. В Windows используйте `python` вместо `python3`.

## Замеры расхода токенов

В шести задачах агент получил **1 346 токенов вывода инструментов вместо 15 008 (−91,0%)**. В каждой паре сравнивали ответы на один вопрос по одним и тем же сгенерированным данным. Все шесть замеров можно повторить локально без модели и API-ключа. [Исходные варианты и команды](docs/benchmarks.md#six-tool-output-measurements)

| Задача | Токены исходного вывода | Токены с LoomHarness | Изменение |
|---|---:|---:|---:|
| Определить результат пяти тестовых прогонов | 8 391 | 316 | -96,2% |
| Найти объявление функции | 1 455 | 81 | -94,4% |
| Узнать статус 60 заданий | 3 956 | 746 | -81,1% |
| Посчитать 24 строки с совпадением | 228 | 12 | -94,7% |
| Посчитать срабатывания по 120 измерениям | 786 | 98 | -87,5% |
| Получить суммарные показатели четырёх агентов | 192 | 93 | -51,6% |

Ещё два прежних замера показывают, что происходит на больших файлах.

- В **журнале из 200 000 строк** нашлось 200 совпадений. Ответ с одним счётчиком занял **12 токенов** против **542** у обычной страницы результатов поиска. [Как измеряли поиск](docs/benchmarks.md#searching-200000-lines)
- Для **журнала из 100 000 строк** оптимизированная команда вернула тот же фрагмент за **40,9 мс** вместо **178,0 мс**. Это медианы по 21 паре запусков CLI на macOS. [Как измеряли время](docs/benchmarks.md#previewing-100000-lines)

## Подключение к агенту

**Codex.** Запустите установщик, откройте `/hooks` в Codex и подтвердите четыре записи LoomHarness. Отправьте в чат проекта `LoomHarness on`. Затем попросите агента запустить тесты, показать сбои и сохранить полный журнал. Выбор для проекта сохраняется локально.

```sh
python3 -X utf8 install.py --cli codex
```

**Другие клиенты.** Установщик поддерживает Claude Code и Gemini CLI. Для OpenCode есть плагин. MCP-сервер работает через stdio и предоставляет пять инструментов для просмотра файлов, поиска, построения карты кода, расчёта метрик и оценки бюджета контекста. В настройках MCP-клиента укажите исполняемый файл Python и абсолютный путь к `loomharness/scripts/mcp_server.py`. [Подключение и поддержка клиентов](integrations/README.md)

## Как выбрать инструмент

| Задача | Что использовать |
|---|---|
| Найти причину сбоя в длинном журнале сборки | `context.py run` сохраняет полный журнал и возвращает код завершения. `view.py --find` показывает совпавшие строки вместе с соседними. |
| Найти ответ в большом отчёте | `view.py --fields` выбирает нужные поля. `metrics.py --summary` возвращает счётчики, покрытие и максимальное значение. |
| Найти реализацию | `context.py map` показывает возможные объявления с путями и номерами строк. С необязательным парсером Tree-sitter команда `context.py symbol` читает Java-метод и его перегрузки. |
| Продолжить долгую задачу | `history.py budget` оценивает, когда сводка сэкономит токены. Доска проекта хранит поручения агентам, сданные результаты и итоги независимой проверки. |
