# LoomHarness

[English](README.md) · **Русский**

LoomHarness помогает ИИ-агентам работать с большими файлами, журналами и таблицами. Он находит нужные строки и значения локально. Модель читает меньше токенов, а полный исходник остаётся под рукой. LoomHarness также помогает повторно использовать проверки и распределять задачи между агентами.

## Экономия токенов и денег

На двух тестовых задачах в Codex сравнили чтение целых файлов с выборкой нужных данных. Все ответы прошли одинаковые проверки.

| Модель | Всего токенов, без → с LoomHarness | Оценка стоимости API, без → с LoomHarness |
|---|---:|---:|
| GPT-6.2 Sol | 75 214 → 35 300 (**−53%**) | $0,0974 → $0,0173 (**−82%**) |
| GPT-6.2 Astra | 75 091 → 35 176 (**−53%**) | $0,3896 → $0,0501 (**−87%**) |

Стоимость рассчитана по тарифу OpenAI API Standard с учётом кеша. Миллион некешированных входных и миллион выходных токенов стоят соответственно $2 и $10 на Sol, $8 и $40 на Astra. [Подробные замеры и тарифы](docs/benchmarks.md#whole-task-token-usage-in-codex)

## Подключение к Codex

Нужен **Python 3.11+** на Windows, macOS или Linux.

1. [Скачайте актуальный ZIP](https://github.com/rubcov666/loomharness/archive/refs/heads/main.zip) и распакуйте его.
2. В папке с `install.py` выполните `python -X utf8 install.py --cli codex`. Если Python запускается командой `python3`, используйте её.
3. Если Codex попросит подтвердить хуки, откройте системный терминал и запустите `codex`. Внутри **Codex CLI** введите `/hooks` и подтвердите четыре записи LoomHarness. Для Codex Desktop используйте CLI с той же конфигурацией Codex. [Настройка хуков Codex](https://learn.chatgpt.com/docs/hooks#review-and-trust-hooks)
4. В чате нужного проекта отправьте `LoomHarness on` и дайте свою задачу.

### Установка через ИИ-агента

Скопируйте этот промпт в чат агента с доступом к терминалу.

```text
Установи и настрой LoomHarness для этого проекта.
Скачай ветку main из https://github.com/rubcov666/loomharness.
По инструкциям в README.md и integrations/README.md выбери способ установки для моей ОС и клиента.
Установи LoomHarness, проверь результат и выполни доступные шаги настройки проекта.
Если мне нужно подтвердить хуки или отправить команду включения, покажи точный шаг.
Для подтверждения хуков Codex направь меня в меню /hooks внутри Codex CLI.
Если закрытый репозиторий недоступен, попроси у меня ZIP.
```

## Инструменты

| Инструмент | Для чего нужен |
|---|---|
| `view.py` | Находит нужные строки и читает выбранные поля. |
| `context.py run` | Сохраняет полный вывод команды и показывает основные ошибки. |
| `context.py map` | Находит подходящие файлы и строки исходников. |
| `records.py` · `metrics.py` | Фильтрует записи, считает итоги и срабатывания. |
| `context.py reuse` · `context.py build-check` | Проверяет, подходят ли результаты предыдущих проверок. |
| `history.py budget` | Подсказывает, когда стоит сжать историю длинного чата. |
| `team.py` · `team.py usage` | Ведёт задачи, ответственных, ревью и расход токенов. |
| `harness.py doctor` · `context.py audit` | Проверяет подключение хуков и находит повторы в инструкциях. |
